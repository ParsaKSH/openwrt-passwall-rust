# OpenWrt package architecture  ->  Rust target used for the static (musl) binary.
#
# Column 3 ("set") selects which arches packaging/build.sh builds by default:
#   core  : built by default (Rust targets x86_64, aarch64, armv7 hard-float, armv6 hard-float)
#   extra : built with ARCHES=all (build.sh runs `rustup target add` for them when RUSTUP_ADD=1)
#   sdk   : no prebuilt Rust std for this target (MIPS, PowerPC, ...): build inside the
#           OpenWrt SDK/buildroot with luci-app-passwall2/Makefile instead.
#
# The binary is fully static, so the float ABI of the router's libc does not matter; what
# matters is that the instruction set is supported by the CPU (e.g. soft-float arches get
# a soft-float binary because their CPUs may have no VFP unit).
#
